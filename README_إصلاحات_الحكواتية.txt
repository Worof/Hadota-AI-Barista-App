# إصلاحات مجتمع قهوة الحكواتية

الحزمة دي بتطبّق إصلاحات المجتمع فقط، من غير تعديل وكيل القهوة أو أسئلته أو تعليماته.

## الملفات اللي بيحدّثها السكربت
- `backend.js`
- `app.js`
- `tests/supabase-adapter.test.mjs`
- `tests/features.py`
- `docs/DEPLOY.ar.md`

## طريقة الاستخدام
1. فكّي ضغط الحزمة داخل مجلد مشروع `Hadota-AI-Barista-App`، أو انسخي السكربت إلى جذر المشروع.
2. شغّليه:
   ```bash
   python apply_hadota_community_fixes.py
   ```
3. السكربت بيحفظ النسخ الأصلية في `.hadota-community-fix-backup/` قبل التعديل.
4. شغّلي الاختبارات:
   ```bash
   npm test
   npm run e2e
   ```

اختبار المتصفح يحتاج تثبيت Playwright وChromium.

## مهم لقاعدة البيانات المنشورة
بعد المخطط الأساسي، لازم تشغيل:
`supabase/migrations/002_social_and_requests.sql`

السكربت لا يتصل بمشروع Supabase ولا يطبّق SQL على قاعدة البيانات. لو كانت الترحيلات أو سياسات التخزين غير مطبقة على مشروعك، نفّذيها من محرر SQL في Supabase.

## ملاحظة
تعذّر حفظ التعديلات مباشرةً في GitHub بسبب صلاحيات تكامل الكتابة. الحزمة دي بتطبّق الإصلاحات على نسخة المشروع المحلية. لم يتم الادعاء بأن الاختبارات اجتازت التشغيل؛ السكربت يفحص صياغة ملفات JavaScript قبل التعديل.
